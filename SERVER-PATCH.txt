ALTERAÇÕES MÍNIMAS NO server.js ATUAL
=====================================

1) Perto dos imports, adicione:

const instagramOAuthRouter = require('./instagramOAuth');

2) Depois destas linhas:

app.use(cors());
app.use(express.json({ limit: '8mb' }));

adicione:

app.use('/api/instagram/oauth', instagramOAuthRouter);

3) Na rota GET /api/instagram/status, troque:

await autenticarFirebase(req);
const data = await testarConexaoInstagram();

por:

const decoded = await autenticarFirebase(req);
const data = await testarConexaoInstagram({ uid: decoded.uid });

4) Na rota POST /api/instagram/publish, troque:

const resultado = await publicarImagemInstagram({ imageUrl: signedUrl, caption: legenda });

por:

const resultado = await publicarImagemInstagram({
  imageUrl: signedUrl,
  caption: legenda,
  uid: decoded.uid,
});

5) No index.html, antes de </body>, adicione:

<script src="./instagram-connect.js"></script>

Esse widget é TEMPORÁRIO só para testar o OAuth. Depois que funcionar,
vale mover o botão "Conectar Instagram" para a tela de Configurações.
